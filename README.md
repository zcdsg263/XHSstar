# 明星穿搭工作台（Windows 共享版）

## 这是什么

这是一个 Windows 桌面工作台。左侧按“选题 → 素材 → 模板识别 → 启动”配置任务，右侧直接打开 ChatGPT 并发送本次任务。它不需要 API Key、不需要安装 Node.js 或 Codex。

## 使用前准备

- Windows 10/11 64 位电脑。
- 正常联网。
- 你自己的 ChatGPT 账号。能否联网、生图及可用额度取决于该账号当前权限。

本共享包不含任何人的 ChatGPT 登录状态、历史聊天、已选素材或任务草稿；首次打开时请自行登录。

## 5 步开始

1. 解压整个 ZIP 到一个普通文件夹，不要在压缩包预览里直接运行。
2. 双击 `app` 文件夹中的 `Celebrity-Outfit-Workbench.exe`。
3. 等右侧 ChatGPT 页面载入；如要求登录，使用自己的账号完成登录。
4. 左侧选择选题与素材来源，选定模板和数量，最后点击“开始任务”。
5. 任务会发送到右侧聊天，生成结果也在右侧 ChatGPT 查看和保存。

“已发送”只表示任务消息已发出，不等于图片已经生成完成。

## 三种素材路线

- **我手动找图**：从微博、小红书等自行保存原图，再上传。素材最可控。
- **Codex 找图后导入**：复制工作台里的采集提示词交给 Codex，导入它收集的实际图片。
- **GPT 官网找图**：不上传明星图，由右侧 ChatGPT 在限定搜索预算内找可用原图；找不到时允许部分交付并说明缺口，不应只回复“0”。

## 当前规则

- 选题推荐优先中国、韩国、日本的文娱艺人，包括演员、歌手、偶像、组合成员、主持人和综艺艺人。
- 其他国家或地区必须同时满足近期热度特别高、中国互联网讨论明显、原图充足和商品可识别，才会被少量推荐。
- 裁剪、抠图、拼合、排版、修复和最终成图只使用 ChatGPT 内置 GPT Image；禁止 Figma。如右侧出现 Figma 或“文件实体化”授权，不要批准。
- 当前界面明确提供 GPT Image 2.5 时优先使用；否则使用 GPT Image 2；未显示版本时不虚构模型版本。

## 常见情况

- **右侧没有登录成功**：点顶部“重载 ChatGPT”，再在右侧完成登录。
- **发送失败**：确认右侧是正常的新聊天、网络正常且 ChatGPT 显示附件入口，然后重试。
- **微博/小红书受限**：这是来源访问受限，工作台会提示缺口；可切换为手动上传或使用官方/品牌/可靠媒体公开图。
- **没有图像生成能力**：这是当前 ChatGPT 账号或会话能力限制，不能自动换成 Figma。

## 想改提示词或节点？

共享包里的 `source-for-customization` 文件夹是给 Codex 或能改代码的 GPT 使用的。先阅读 `GPT-Codex-Customization-Guide-zh-CN.md`，再把该指南和相关源码文件交给它。普通 ChatGPT 可以帮你理解和起草修改；要真正改出新的 EXE，需要按指南在 Windows 上重新构建。
